\subsection{ANOVA Test}
An ANOVA analysis was conducted on the runtime data for each workload and run length combination. The values were calculated using the equations below:

\begin{align}
d_i &= O_i-R_i, \\
\bar d &= \frac{1}{n}\sum_{i=1}^{n}d_i, \\
s_d^2 &= \frac{1}{n-1}\sum_{i=1}^{n}(d_i-\bar d)^2, \\
F &= \frac{n\bar d^{\,2}}{s_d^2},
\qquad df_1=1,\quad df_2=n-1, \\
p &= \Pr\!\left(F_{1,n-1}\ge F_{\mathrm{observed}}\right).
\end{align}

This performs a two-condition repeated-measures ANOVA test comparing the runs of regular and overloaded workloads. Results are split into four tables by workloads and only rows resulting in significance are shown:

\subsection{Chi-Squared Test}

A Chi-Squared test was also performed on the run data for each workload and run length to determine the significance of differences between the regular and overloaded runs. The Chi-Squared test was performed using the following equations:

\begin{align}
I &= \sum_{i=1}^{n}\mathbf{1}(O_i>R_i), \\
D &= \sum_{i=1}^{n}\mathbf{1}(O_i<R_i), \\
m &= I+D,\qquad E_I=E_D=\frac{m}{2}, \\
\chi^2
&= \frac{(I-m/2)^2}{m/2}
 + \frac{(D-m/2)^2}{m/2}
 = \frac{(I-D)^2}{m}, \\
df &= 1, \\
p &= \Pr\!\left(\chi^2_1\ge\chi^2_{\mathrm{observed}}\right).
\end{align}

Like the ANOVA test, this is separated into 4 tables based on workload. Only rows resulting in significance are shown.
